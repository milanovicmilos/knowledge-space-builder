I'm building a knowledge space construction system for educational assessment data as part of an academic project in collaboration with Pädagogischen Hochschule St.Gallen (PHSG). The goal is to construct and visualize a knowledge space over real mathematics test data that shows student ability distributions and learning trajectories. I need to implement a Multidimensional Item Response Theory (MIRT) combined with a Variational Autoencoder (VAE) approach because this handles sparse educational data better than alternatives and provides both psychometric interpretability and modern deep learning capabilities.

THE DATA: I have a semicolon-separated CSV with 220,000+ students (rows) and 120 mathematics questions (columns). First column is T_Grade (student grade). Each cell contains 0 (incorrect answer), 1 (correct answer), or NA (question not answered). The matrix is 95% sparse - each student typically answers only 5-20 questions out of 120. Question IDs are like M178832, M178357, etc.

THE APPROACH: Implement a two-stage pipeline. Stage 1 uses Multidimensional IRT (MIRT) to extract latent ability dimensions from the sparse response matrix - this is the psychometric foundation that estimates student abilities and question difficulties while naturally handling NA values through maximum likelihood estimation. Stage 2 uses a Variational Autoencoder that takes the MIRT-estimated ability vectors as input and learns a continuous lower-dimensional knowledge space suitable for visualization, where students with similar knowledge states cluster together.

STAGE 1 - MIRT IMPLEMENTATION: Use the mirt package approach (can use py-irt or implement custom EM algorithm) to fit a multidimensional IRT model with 5-8 latent dimensions on the sparse binary response matrix. The model should estimate theta parameters (student abilities per dimension), a parameters (item discrimination), and b parameters (item difficulty). Handle NA values properly by excluding them from likelihood calculations - do not treat NA as incorrect or impute them. Output should be a matrix of shape (n_students, n_dimensions) containing estimated ability scores for each student across latent dimensions like algebra, geometry, statistics, etc. Also extract item parameters for interpretation.

STAGE 2 - VAE FOR KNOWLEDGE SPACE: Build a Variational Autoencoder in PyTorch that takes MIRT ability vectors as input. The encoder should map from MIRT dimensions (5-8D) to a 2-3 dimensional latent space suitable for visualization. Use a standard VAE architecture with encoder outputting mu and logvar, reparameterization trick for sampling, and decoder reconstructing the original MIRT ability estimates. The loss function should be reconstruction loss (MSE between input and reconstructed MIRT abilities) plus KL divergence regularization. Train this on all student ability vectors to create a smooth continuous knowledge space where similar students are nearby and you can interpolate between knowledge states.

TRAINING DETAILS: For MIRT use Expectation-Maximization algorithm iterating until convergence (monitor log-likelihood changes). For VAE train for 100-200 epochs with Adam optimizer, learning rate 0.001, batch size 256. Use early stopping based on reconstruction loss. The VAE latent space coordinates become the final knowledge space representation - each student gets a 2D or 3D position that represents their knowledge state.

VISUALIZATION REQUIREMENTS: Create an interactive visualization showing the 2D or 3D knowledge space with students as points colored by their grade (T_Grade) or total score. Add ability to hover over points to see individual student abilities per dimension. Plot item characteristic curves (ICC) showing probability of correct response as a function of ability for selected questions. Show the distribution of question difficulties on the ability scale. Create a heatmap showing predicted responses for all student-question pairs including the originally NA values - this demonstrates the model's ability to fill the sparse matrix.

OUTPUT THE MODEL MUST PROVIDE: Trained MIRT model with estimated theta (abilities), a (discrimination), and b (difficulty) parameters. Trained VAE model that maps abilities to 2D/3D knowledge space. For each student: position in knowledge space (2D/3D coordinates), ability estimates per dimension, predicted probability of correctness on all 120 questions. For each question: difficulty and discrimination parameters, which dimensions it loads on. Ability to predict responses for new students given partial response patterns.

WHY THIS APPROACH: MIRT is the gold standard in educational measurement used by PISA, SAT, and major assessments - it naturally handles sparse matrices through maximum likelihood estimation that only uses observed responses. It provides interpretable dimensions representing different mathematical skills. The VAE adds modern deep learning to create a continuous smooth knowledge space suitable for visualization and interpolation between students. This combination gives both psychometric rigor (MIRT) and visualization power (VAE). The knowledge space shows student clusters, learning trajectories, and allows prediction of performance on unobserved questions - exactly what's needed for educational assessment and adaptive testing.

IMPLEMENTATION: Write clean modular Python code using PyTorch for VAE, numpy/scipy for MIRT (or py-irt library if simpler), and plotly or matplotlib for interactive visualization. Include detailed comments explaining the IRT estimation process and how NA values are handled. Show training progress with loss curves. Generate the final knowledge space visualization as an interactive HTML plot where you can rotate the 3D space and inspect individual students.
